# MP61-N01 Hardware Profile

## Overview

`MP61-N01` is the first experimental node in the MacPro6,1 Local LLM Lab.

This document records the hardware configuration of the machine before
major hardware upgrades or thermal-interface refurbishment.

The initial configuration is designated:

**S0 — As Acquired**

## CPU

The original CPU is an Intel Xeon E5-1620 v2.

- Architecture: Ivy Bridge-EP
- Cores: 4
- Threads: 8
- Base frequency: 3.7 GHz
- ECC memory support

This CPU configuration is used as the S0 baseline before the planned
upgrade to a higher-core-count Xeon E5 v2 processor.

## Memory

The S0 configuration contains:

- 12 GB DDR3-1866 ECC memory
- 3 × 4 GB DIMMs
- One memory slot unused

The memory configuration will be preserved during the initial CPU
upgrade so that CPU performance can be compared before and after the
upgrade with memory capacity unchanged.

## GPU

The system contains two AMD FirePro D300 GPUs.

Each GPU provides:

- 2 GB dedicated VRAM
- 20 Compute Units detected by the Linux OpenCL stack

The two GPUs have independent VRAM spaces. They must not be treated as
a single unified 4 GB GPU.

Under Debian 13, both GPUs are detected using the Linux `radeon` driver.

OpenCL functionality has been verified using Mesa Rusticl.

## Storage

The original storage device is an Apple 256 GB SSD.

SMART health status was checked before long-duration qualification
testing and reported no critical SMART failures.

## Thunderbolt 2

The MacPro6,1 provides six physical Thunderbolt 2 ports across three
Thunderbolt buses.

All six physical ports were tested for basic connectivity before the
Debian installation.

Thunderbolt networking will be evaluated separately as part of the
multi-node cluster experiments.

## Cooling

The MacPro6,1 uses a shared Thermal Core cooling architecture for the
CPU and both GPUs.

A single main system fan provides airflow through the Thermal Core.

Under Debian 13, fan monitoring and control are available through the
Linux `applesmc` driver.

Observed fan range:

- Minimum: approximately 790 RPM
- Maximum: approximately 1900 RPM

A custom fan controller is used during thermal qualification testing.

See:

[Fan control methodology](../methodology/fan-control.md)
